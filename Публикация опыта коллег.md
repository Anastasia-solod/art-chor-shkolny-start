# Как опубликовать материал в разделе «Опыт коллег»

Педагог направляет материал через раздел «Делюсь опытом» на почту центра. После согласования публикации с автором отредактируйте файл `Опыт коллег.js` и добавьте объект в массив `window.colleagueMaterials`:

```js
window.colleagueMaterials = [
  {
    title: 'Название разработки',
    author: 'Имя автора',
    organization: 'Школа или учреждение',
    age: '7–12 лет',
    category: 'Сценарий занятия',
    description: 'Краткое описание практики и её цели.',
    file: 'Опыт коллег/Название файла.pdf'
  }
];
```

Если файла нет, удалите поле `file`: карточка с описанием всё равно появится. Если файл есть, поместите его в папку `Опыт коллег` рядом с сайтом; поддерживаются PDF, DOCX и HTML. Затем заново опубликуйте папку сайта на Vercel. Почтовые сообщения сами по себе на публичный сайт не попадают.
